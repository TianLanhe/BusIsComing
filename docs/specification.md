# BusIsComing 規格説明

## 常用行程結果置頂

- 置頂只適用於常用頁目前已選的已保存行程；搜尋頁不提供置頂。
- 未置頂卡右滑成為本次置頂；本次置頂再右滑成為長期置頂。
- 本次或長期置頂卡左滑均直接取消；取消 Snackbar 提供撤銷。
- 長期置頂卡右滑不更新 token、不寫入、不震動、不顯示 Snackbar，只回彈。
- 有效滑動門檻為卡片邊緣 16dp 留白加目前語言動作文字的實際量測寬度；文字完整露出即達門檻，不允許速度越過距離門檻。
- 卡片最大可見位移為有效門檻加 8dp；不得繼續滑出畫面或進入 swipe-to-dismiss。
- 釋放卡片後必須先回到零水平位移，再執行達門檻的置頂、升級、取消或不可用提示；未達門檻不執行動作。
- 所有滑動方向均不繪製底色，只露出頁面既有背景與適配明暗主題的動作文字。
- ETA 可點擊區與鈴鐺 48dp 觸控區必須保持原操作，不得被置頂手勢搶佔。

## 排序與展示

- 所有本次及長期置頂按 `pinnedAt` 降序排列，後置頂在上。
- 本次升級長期時保持原 `pinnedAt`，不得移到置頂區頂部。
- 目前排序字段及方向只重排未置頂結果。
- 置頂與未置頂同時存在時，插入「以下 N 條按〈字段〉〈方向〉排序」分隔列。
- 分隔列不計入路線數量，不可點擊、不可滑動、非 sticky。
- 首次把普通卡設為本次置頂時，卡片成為置頂區第一項，清單在差異移動後顯示結果頂部。
- 本次置頂升級長期時保持原位置及目前視口；取消、排序、刷新、ETA 及站點更新亦保持適當閱讀視口，不得複製或遺失路線。
- 連續兩次右滑後，同一穩定 identity 的卡片必須回到零水平位移、保持可見並顯示長期書籤，不得留下空白卡位。

## 保存與恢復

- 本次置頂在同一 task 的頁面切換、排序、刷新、旋轉、語言或主題導致的 Activity 重建中保留。
- 全新啟動、切換已保存行程、修改起終點或刪除行程時，不恢復對應本次置頂。
- 長期置頂按行程 id 保存至 SQLite；查詢暫時沒有匹配結果時仍保留。
- 空結果或 Citybus 查詢失敗不得刪除或改寫任何置頂偏好。
- 長期置頂讀取失敗時，路線仍按普通結果展示並提供一次非阻塞提示。

## 路線身份

- 只有全部乘車段均具有 company、公開路線號、variant、bound、direction path、boarding sequence 及 alighting sequence 時才可置頂。
- 指紋必須帶版本前綴並使用固定、有歧義免疫的字段編碼。
- 同一次查詢內重複嚴格指紋的所有卡片均不可置頂。
- 指紋版本或完整內容不一致時不得以路線號、名稱或 `resultId` 模糊恢復。

## 持久化一致性

- 長期升級與取消採樂觀 UI；資料庫失敗時恢復原 level、token 與位置。
- 快速相反操作、取消後立即撤銷及舊 callback 必須以每指紋 mutation generation 保證最後意圖勝出。
- 長期置頂讀取不得覆蓋讀取開始後發生的置頂、取消或撤銷；合併時以讀取開始時的每指紋 mutation generation 為基準。
- 排隊中的長期置頂寫入必須在同一 transaction 核對操作開始時的行程起終點；作用域已改變時不得重新插入舊路線置頂。
- 只改行程名稱保留全部置頂。
- 修改起終點且存在 N 條長期置頂時，保存前顯示數量確認；確認後在同一 transaction 更新行程並清除長期置頂。
- 刪除行程與取代匯入依外鍵級聯清除被刪除行程的長期置頂。
- 複製、合併新增及取代新增的行程不繼承任何置頂。
- `.bicroutes` v1 仍只包含名稱與起終點，不包含指紋、token 或置頂等級。

## 視覺、本地化與無障礙

- 本次置頂只增加強調描邊；長期置頂另顯示左側短書籤，不增加卡片內容行或改變鈴鐺區。
- 普通卡提供「本次置頂」無障礙 action；本次置頂卡提供「長期置頂」及「取消置頂」；長期置頂卡提供「取消置頂」。
- 書籤為裝飾性 view，不單獨朗讀；分隔列朗讀完整數量、排序字段及方向。
- 置頂狀態、Snackbar、錯誤、分隔列與無障礙 action 必須提供香港繁體、簡體及自然英文。
