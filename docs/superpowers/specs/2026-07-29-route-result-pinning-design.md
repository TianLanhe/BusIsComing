# 常用頁路線結果置頂設計

日期：2026-07-29

狀態：已確認

範圍：常用頁的 Citybus 路線查詢結果

## 背景

常用行程查詢可能返回大量巴士路線候選。現有排序支援路線、價格、耗時、候車與步行距離，但用戶有時需要特別關注某一條候選路線，不希望該路線因排序切換、ETA 更新或刷新而離開列表頂部。

本設計在現有排序之上增加用戶主動控制的置頂層，並區分：

- **臨時置頂**：只屬於目前常用行程的當前 App 任務會話。
- **長期置頂**：持久保存於目前常用行程，重新啟動 App 後可按嚴格乘車方案身份恢復。

置頂不是第六種排序字段。置頂路線先按置頂時間排列，其餘路線再按目前排序字段與方向排列。

## 目標

- 讓用戶在長結果列表中以橫滑快速置頂一條路線。
- 讓用戶把臨時置頂升級為按常用行程保存的長期置頂。
- 保持置頂區不受普通排序、ETA 增量更新及刷新影響。
- 讓後置頂路線位於先置頂路線之上。
- 不為置頂操作增加常駐卡片按鈕、操作欄或額外卡片高度。
- 以差量列表更新提供跟手、穩定、不跳動的橫滑與重排動效。
- 在繁體、簡體、英文、明暗模式、大字體與 TalkBack 下保持可理解及可操作。

## 非目標

- 搜尋頁不提供置頂。
- 不為置頂增加首次引導、提示條、管理頁或長按入口。
- 不限制臨時或長期置頂數量。
- `.bicroutes` 版本 1 不匯出或匯入長期置頂。
- 不跨不同常用行程共享置頂。
- 不以路線號相似、模糊匹配或機器推斷恢復長期置頂。
- 不修改 Citybus、DATA.GOV.HK 或 Google 的請求參數與解析語義。

## 核心行為

### 狀態機

| 目前狀態 | 向右滑動 | 向左滑動 |
| --- | --- | --- |
| 普通路線 | 升級為臨時置頂 | 不移動、不執行動作 |
| 臨時置頂 | 升級為長期置頂 | 取消全部置頂 |
| 長期置頂 | 顯示「已長期置頂」並回彈 | 取消全部置頂 |

向左滑動長期置頂會直接刪除長期偏好並移回普通排序區，不先降級為臨時置頂。

### 置頂順序

- 臨時與長期置頂共用同一個置頂時間隊列。
- 新置頂的路線位於所有既有置頂路線之上。
- 新置頂的 `pinnedAt` 使用 `max(目前時間, 目前已知最大 pinnedAt + 1)`，即使系統時鐘回撥或兩次操作落在同一毫秒，亦保持嚴格的後置頂優先次序。
- 臨時置頂升級為長期置頂時保留原 `pinnedAt`，不得因升級再次移到頂部。
- 重新啟動 App 後只恢復長期置頂，並保持其原相對順序。
- 新會話產生的臨時置頂位於較早保存的長期置頂之上。
- ETA、站點預覽、價格、耗時或其他展示資料更新不得改變置頂時間。

### 與普通排序組合

- 置頂區完全忽略路線、價格、耗時、候車與步行距離排序。
- 普通路線區繼續使用既有 `BusRouteSorter` 規則。
- 切換排序只重排普通路線。
- 取消置頂後，卡片進入目前普通排序所決定的位置。
- 撤銷取消時恢復原置頂等級、置頂時間及相對位置。
- 結果摘要仍顯示去重後的總路線數，置頂不得新增、複製或遺漏路線。
- 至少有一條置頂及一條普通路線時，在兩區之間顯示橫分隔線，例如「以下 10 條按耗時 ↑ 排序」。
- 沒有置頂路線或全部路線均已置頂時，不顯示無意義分隔線。

### 長列表視口

- 在結果列表較深位置置頂卡片後，卡片立即進入列表頂部的置頂隊列。
- 目前視口保持原滾動位置，不自動跳到頂部。
- 被移走卡片之後的普通路線自然補位。
- Snackbar 提供即時確認與長期升級，因此用戶不需要為了升級立即回到頂部。

## 橫滑互動與反饋

### 觸發規則

- 只有手勢明顯以水平方向為主時才拖動卡片；垂直手勢繼續控制列表滾動。
- 卡片以 1:1 位移跟隨手指。
- 滑過卡片寬度約 40% 才提交動作；未達閾值時回彈並保持原狀態。
- 不使用只靠高速、短距離 fling 提交的捷徑。
- 越過可提交閾值時提供一次輕微震動。
- ETA 可點擊區及通知鈴鐺的觸控範圍不啟動置頂橫滑。
- 普通路線向左滑時不移動。
- 長期置頂向右滑時可短暫顯示「已長期置頂」，鬆手後回彈，不震動、不顯示 Snackbar、不改變時間及不寫入資料庫。

### 背景文案

橫滑背景在提交前顯示當次動作的準確文案：

- 普通路線向右：臨時置頂。
- 臨時置頂向右：長期置頂。
- 任一置頂向左：取消置頂。
- 長期置頂向右：已長期置頂。

### Snackbar

- 第一次右滑完成：`118 已在本次置頂`，action 為 `長期置頂`。
- 從 Snackbar 或再次右滑升級成功：`118 已為「上班」長期置頂`。
- 左滑取消：`已取消置頂 118`，action 為 `撤銷`。
- 撤銷恢復操作前的置頂等級、置頂時間及相對位置。
- Snackbar 消失後，臨時置頂仍可透過再次向右滑動升級為長期置頂。
- 不提供首次右滑引導；用戶透過探索發現手勢。

## 視覺設計

### 臨時置頂

- 保持現有卡片尺寸、信息結構與觸控區。
- 使用語意色強調描邊表示卡片已進入置頂區。
- 不增加文字 badge、卡片按鈕或獨立狀態行。

### 長期置頂

- 沿用臨時置頂的強調描邊。
- 在卡片左側增加書籤短帶，作為不只依賴顏色的持久狀態標記。
- 書籤建議約 `10dp × 25dp`，位於現有 `14dp` 左內距內，不改變卡片寬高，不壓縮路線號。
- 書籤使用底端缺口形狀，避免被理解為純選中框。
- 書籤不得放在右上角，以免與 ETA、下一班及 `48dp` 鈴鐺觸控區衝突。
- 淺色與深色模式使用對應 `bus_*` 語意色，不硬編碼固定顏色。

### 區域分隔

- 不在置頂區頂部增加「置頂路線」標題行。
- 在最後一張置頂卡片與第一張普通卡片之間顯示單一橫分隔線。
- 分隔線同時説明普通區的路線數、排序字段與方向。
- 分隔線是列表 item，不屬於任一卡片，不吸頂，也不可滑動。

## 動效

- 拖動時卡片與手指 1:1 跟隨，背景文案依進度漸顯。
- 未提交手勢使用短促彈性回彈。
- 提交後以差量 move／insert／remove 動畫讓其他卡片自然補位。
- 建議位移與回彈時間約為 180–240ms。
- 置頂或取消不得自動捲動列表。
- 動畫不得阻塞再次滾動、卡片詳情、ETA 或鈴鐺操作。
- 系統動畫比例為 `0` 時立即完成狀態變化，不強制播放位移。
- 不使用 `notifyDataSetChanged()` 執行置頂重排，避免整列表閃爍。

## 作用範圍與生命週期

### 按常用行程隔離

- 每個長期置頂只屬於一個 `RouteConfig`。
- 同一路線可以在「上班」長期置頂，但不影響「回家」或其他常用行程。
- 搜尋頁不讀取、不展示及不修改置頂狀態。
- 複製常用行程時，新行程不繼承原置頂。

### 臨時置頂會話

臨時置頂在以下情況保留：

- 切換排序。
- ETA 或站點預覽增量更新。
- 同一行程下拉刷新或重新查詢。
- 切換到搜尋／設定後返回常用頁。
- 旋轉、切換語言或主題，以及 Android 在同一 task 內重建 Activity。
- 路線暫時未返回；在同一會話稍後重新匹配時恢復。

臨時置頂在以下情況清除：

- 查詢另一個常用行程。
- 修改目前行程的起點或終點。
- 刪除目前行程。
- 用戶左滑取消。
- 用戶從最近任務移除 App、強制停止或之後全新啟動。

### 長期置頂未匹配

- 成功查詢未返回某條長期置頂路線時，不顯示空位、過期卡片、數量或錯誤。
- 長期偏好保持為未匹配狀態，不因一次或多次缺失自動過期。
- 之後嚴格身份重新匹配時恢復原置頂時間與順序。
- 查詢失敗不得刪除或修改長期偏好。

## 嚴格乘車方案身份

### 不可使用的身份

現有 `resultId` 包含價格、耗時、步行距離及 `rawInfo` 等可能變化的資料，不適合長期持久身份。

單獨使用 `118` 或 `85 → 106` 等路線號序列亦不安全，因為相同路線號可能對應不同公司、route variant、方向、上落車站或乘車段。

### 版本化指紋

`routeFingerprint` 由每個乘車段依順序編碼：

- 公司。
- 公開路線號。
- route variant。
- bound。
- direction path。
- 上車序號。
- 下車序號。

指紋不得包含：

- App 或外部資料展示語言。
- 地點或站名顯示文字。
- 價格、耗時、步行距離或 ETA。
- 當次 Citybus `rawInfo`。
- 目前排序或卡片視覺狀態。

指紋以版本前綴自我描述，例如 `v1|...`。編碼器必須使用固定字段順序及無歧義 escaping 或長度編碼，不得直接把未轉義外部字串以分隔符拼接。

未來身份算法變更時使用新前綴，例如 `v2|...`，避免新代碼錯誤解讀舊記錄。舊記錄可由明確遷移或兼容策略處理；在沒有策略時保持未匹配，禁止寬鬆猜測。

### 異常身份

- 如果查詢結果缺少必要結構，無法建立嚴格指紋，橫滑後回彈並提示「暫時無法置頂此路線」。
- 不得以路線號、價格或 `resultId` 作為長期指紋 fallback。
- 如果同一結果集出現兩張具有相同嚴格指紋的卡片，視為身份歧義；兩者不得進入長期置頂，並記錄不包含敏感資料的診斷資訊。

## SQLite 設計

資料庫 schema 由版本 3 非破壞性升級為版本 4。

```sql
CREATE TABLE route_result_pins (
    route_config_id INTEGER NOT NULL,
    route_fingerprint TEXT NOT NULL,
    pinned_at INTEGER NOT NULL,
    PRIMARY KEY (route_config_id, route_fingerprint),
    FOREIGN KEY (route_config_id)
        REFERENCES route_configs(id)
        ON DELETE CASCADE
);

CREATE INDEX index_route_result_pins_journey_time
ON route_result_pins(route_config_id, pinned_at DESC);
```

- `route_fingerprint` 自帶 `v1|` 等算法版本前綴，不另設版本欄。
- `pinned_at` 保存最初進入置頂隊列的嚴格遞增排序時間；升級長期不得重寫此值，亦不把它展示為用戶可見時間。
- `SQLiteOpenHelper.onConfigure` 啟用 foreign keys。
- 新安裝在 `onCreate` 建立兩張表與索引。
- v3→v4 的 `onUpgrade` 只建立新表與索引，不刪除、重建或改寫 `route_configs`。

## 元件邊界

### `PinnedRouteRepository`

負責：

- 按常用行程讀取長期置頂，依 `pinned_at DESC` 返回。
- 在不存在時插入長期置頂；記錄已存在時保留原 `pinned_at`，不得用重複操作刷新順序。
- 刪除單一長期置頂。
- 計算某行程的長期置頂數量。
- 清理行程的全部長期置頂。

它不負責：

- Citybus 查詢。
- 普通排序。
- UI 文案、Snackbar 或動效。
- 臨時置頂生命週期。

### `RoutePinSessionState`

負責目前常用行程會話中的：

- 路線指紋。
- `TEMPORARY`／`PERSISTENT` 等級。
- 原置頂時間。
- 未匹配狀態。
- saved instance state 序列化與恢復。
- 操作前快照及撤銷。

### `PinnedRouteProjector`

以純函數接收：

- 目前查詢結果。
- 目前普通排序字段與方向。
- 目前置頂狀態。

輸出：

- 依置頂時間倒序的 `RouteCardItem`。
- 必要時一個 `UnpinnedDividerItem`。
- 依既有排序排列的普通 `RouteCardItem`。

它不得讀寫 SQLite、發起網絡請求或直接操作 View。

### `RouteQueryState`

- 繼續持有原始查詢結果、排序、更新時間、錯誤與刷新狀態。
- 透過 projector 取得展示列表。
- ETA／站點預覽更新只替換對應 `BusRouteOption`。
- 既有 `BusRouteSorter` 保持普通排序職責，不感知置頂。

### `BusRouteAdapter`

- 由目前可變列表與 `notifyDataSetChanged()` 遷移至 `ListAdapter`／`DiffUtil` 或等價差量實現。
- 使用嚴格路線指紋作為可用時的穩定 item identity；無嚴格指紋的不可置頂路線使用 query result identity。
- 支援路線卡與分隔線兩種 view type。
- `ItemTouchHelper` 只附加到路線卡。
- 現有整卡詳情、ETA 與鈴鐺 callback 保持獨立。

## 查詢與資料流

### 首次查詢

```text
捕獲 routeConfigId + queryGeneration
├── Citybus 路線查詢
└── SQLite 長期置頂讀取
        ↓
兩者完成或置頂讀取明確失敗
        ↓
合併臨時／長期狀態
        ↓
普通排序 + 置頂投影
        ↓
DiffUtil 提交展示列表
```

- 首次展示等待本機置頂讀取完成，避免普通順序先閃現再跳到置頂順序。
- SQLite 讀取應在專用單線程 executor 執行，不阻塞主線程或網絡查詢 executor。
- 置頂讀取失敗時仍展示路線結果，本次不恢復長期狀態並提供一次非阻塞提示。

### 刷新與增量更新

- 同一行程刷新保留目前臨時及長期狀態。
- 刷新返回新結果後重新嚴格匹配，不保留已不存在的舊卡片。
- 刷新未匹配的置頂狀態保持在 session／SQLite 中，等待之後恢復。
- ETA 更新後重新產生展示 item，但不得重排置頂區。
- 候車排序只重排普通區。
- 任何舊 query generation 的路線、ETA、站點預覽或讀取 callback 不得覆蓋目前行程。

### 寫入與競態

- 長期保存及取消使用專用單線程 executor 串行寫入。
- 同一指紋以遞增 mutation generation 標記寫入意圖；重複手勢不得建立重複記錄，舊 callback 不得覆蓋較新的用戶意圖。
- 寫入攜帶明確的 `routeConfigId` 與 `routeFingerprint`；切換行程後寫入仍可完成，但 callback 不得修改新行程 UI。
- UI 使用樂觀更新：
  - 升級時先顯示書籤，再寫 SQLite。
  - 取消時先移回普通區，再刪除 SQLite。
- 保存失敗時回復臨時置頂，提示「無法保存長期置頂，請稍後重試」。
- 取消失敗時回復原長期等級、時間與位置，提示「無法取消長期置頂，請稍後重試」。
- 用戶在長期刪除完成前點擊「撤銷」時，立即恢復 UI，並在同一串行 executor 中把恢復寫入排在刪除之後；最終資料庫狀態必須以撤銷這個較新意圖為準。
- 臨時置頂只修改記憶體狀態，不發生本機持久化錯誤。

## 行程編輯、刪除與傳輸

### 重命名

- 只修改常用行程名稱時保留臨時及長期置頂。
- 長期 Snackbar 與其他 UI 使用最新行程名稱。

### 修改起終點

- 如果行程已有長期置頂，保存前顯示：
  - 「修改起點或終點將清除該行程的 N 條長期置頂路線」。
  - 操作為返回及繼續保存。
- 用戶確認後，在同一 SQLite transaction 中更新行程並刪除其長期置頂。
- 當前臨時置頂同步清除。
- transaction 失敗時行程與置頂均保持原狀。

跨表原子操作由 `RouteConfigRepository` 的行程變更方法或等價的同資料庫 transaction 邊界負責；不得由兩個互不共享 transaction 的 repository 先後寫入。

### 刪除與取代

- 刪除行程時由 foreign key cascade 刪除其長期置頂。
- `REPLACE` 匯入刪除全部現有行程時，在同一 transaction 中級聯清除置頂。
- 合併匯入只新增沒有置頂的新行程。

### `.bicroutes`

- 格式版本 1 繼續只包含行程名稱與起終點。
- 不新增置頂字段，不升級傳輸格式。
- 匯入行程不建立長期置頂。

## 錯誤處理

- 長期置頂讀取失敗：展示正常路線，暫不恢復長期狀態，限次提示。
- 長期保存失敗：回復臨時狀態，保留用戶目前查詢與普通排序。
- 長期取消失敗：回復原長期狀態及順序。
- 嚴格身份缺失或歧義：不提交置頂，卡片回彈並提示。
- 查詢失敗：沿用既有刷新／查詢錯誤策略，不修改置頂資料。
- 刷新返回空結果：不展示置頂卡或分隔線，但保留同一會話的臨時狀態及 SQLite 長期偏好。
- 所有錯誤文案必須提供繁體、獨立簡體與自然英文，不暴露內部 fingerprint、rawInfo 或 SQLite 詳情。

## 無障礙與本地化

### TalkBack

由於 TalkBack 佔用觸控滑動進行焦點導航，每張路線卡必須按狀態提供自定義 accessibility action：

- 普通：臨時置頂。
- 臨時：升級為長期置頂、取消置頂。
- 長期：取消置頂。

卡片 content description 應包含臨時／長期置頂狀態，但不得重複朗讀純裝飾書籤。

分隔線朗讀完整語義，例如「以下 10 條路線按耗時升序排序」，不可只朗讀箭頭字符。

### 三語

所有新增文案放入 Android resources，不在 XML 或 Kotlin 硬編碼。代表性 mapping：

| 語義 | 繁體 | 簡體 | English |
| --- | --- | --- | --- |
| 臨時動作 | 暫時置頂 | 临时置顶 | Pin for now |
| 長期動作 | 長期置頂 | 长期置顶 | Keep pinned |
| 取消 | 取消置頂 | 取消置顶 | Unpin |
| 已是長期 | 已長期置頂 | 已长期置顶 | Already kept pinned |

最終英文需結合 Snackbar、背景動作與 accessibility action 的句法分別審校，不以逐字直譯取代自然表達。

## 驗證

### 純邏輯單元測試

- 三級狀態機的所有左右滑轉移。
- 長期向右滑不改變資料。
- 取消及撤銷恢復原等級、時間及順序。
- 後置頂位於先置頂之上。
- 升級長期不刷新置頂時間。
- 普通排序只作用於普通區。
- ETA 排序更新不重排置頂區。
- 全部置頂、沒有置頂及部分置頂的分隔線規則。
- 未匹配置頂保留與重新匹配。
- 無數量上限。

### 指紋測試

- 字段順序固定且編碼無歧義。
- 語言、價格、耗時、步行距離、ETA 與 `rawInfo` 變化不影響指紋。
- 公司、route variant、方向、上下車序號或乘車段順序變化會改變指紋。
- `v1|` 前綴存在。
- 缺少必要字段及重複指紋被判定為不可置頂。

### SQLite 與 repository 測試

- v3→v4 migration 保留全部既有行程與使用統計。
- 新表唯一約束及時間索引存在。
- 刪除行程級聯刪除長期置頂。
- 只重命名保留置頂。
- 修改起終點以同一 transaction 清理置頂。
- transaction 失敗完整回滾。
- 合併匯入不建立置頂；取代匯入清除被刪行程的置頂。
- `.bicroutes` v1 schema 保持不變。

### Adapter 與互動測試

- 差量更新使用穩定 identity，不整表刷新。
- 分隔線不可滑動。
- ETA 與鈴鐺點擊不觸發橫滑。
- 40% 閾值前回彈、越過後只震動一次。
- 普通向左不移動。
- 長期向右顯示狀態並回彈。
- 深列表置頂後保持目前視口。
- 快速連續排序、刷新與置頂不接受過期 callback。

### 視覺與手動驗證

覆蓋：

- 繁體、簡體、英文。
- 淺色、深色。
- 約 360dp portrait。
- font scale 1.0、1.3、2.0。
- 一條、多條、全部置頂。
- 單段與多段路線號。
- 可用 ETA、載入、暫無車輛及暫不可用。

重點確認：

- 書籤不遮擋路線號。
- ETA 與 `48dp` 鈴鐺保持完整。
- 分隔線文字可換行或適配，不縮小核心字體。
- 橫滑跟手、回彈與補位無閃爍或整列表跳動。
- 系統關閉動畫時功能仍正確。
- TalkBack 可完成臨時、長期及取消操作。

Android 實現完成後運行：

```bash
./gradlew build
```

如有可用模擬器或真機，額外執行實際橫滑、明暗模式、大字體及 TalkBack 驗收。
