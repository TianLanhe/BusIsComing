# 場景契約與 manifest

## 目的

場景契約把「想展示某功能」轉成可構建、可驅動、可驗收的單次截圖任務。它同時是執行前確認書與執行後證據清單；不要把未討論的產品決定留給截圖階段猜測。

## 理解功能意圖

唯讀閱讀相關 OpenSpec、docs、production UI、resources、model、repository、navigation 與 instrumentation。從使用者表述中明確回答：

- 想證明的功能價值是什麼，而不只是頁面名稱。
- 使用者從哪個真實入口進入，截圖前做了什麼。
- 畫面是初始、載入、成功、空、部分失敗、錯誤、確認、通知還是權限狀態。
- 哪一個 action、數值或視覺層級必須成為焦點。
- 哪些 UI 不應出現；系統 UI 是否屬於場景。
- 一張是否足夠；只有不同狀態不可在同一張完整表達時才增加張數。

若同一句需求可合理解釋成不同狀態，先列出差異並請使用者選擇。不要以過去五張 demo 推斷本次一定需要首頁、詳情、ETA 或鎖屏。

## 模板

把以下模板完整填入會話供使用者確認。獲批後原樣寫到系統暫存 `manifest.md`。不得保留 `TODO`、`TBD`、空 checkbox、「待補」或「待定」等 placeholder。

```markdown
# 截圖任務清單

## 原始需求

- 使用者原意：用一句話忠實重述本次想展示的功能與用途。
- 本次覆寫：列明使用者指定的資料、語言、主題、尺寸或其他例外；沒有覆寫就寫「無」。

## 場景契約

- 場景 slug：`feature-state`
- 任務狀態：`planned`
- 功能價值：說明這張圖要讓觀看者理解什麼。
- 真實入口：說明 Activity／Fragment／設定入口與必要操作。
- 起始狀態：說明 App、資料、權限及系統狀態。
- 截圖時刻：列出可觀察的穩定條件，而非固定等待秒數。
- 視覺焦點：指出主要元件、文案或狀態。
- 排除項：列出不得出現的 UI、資料與中間狀態。

## 截圖清單

- `01-feature-state.png`：描述唯一畫面、截圖模式與它證明的事情。

## 合成資料

- 地點與站點：列出全部可見虛構名稱及碰撞檢查方法。
- 路線與班次：列出可見合成 route／ETA／時間及一致性規則。
- 其他狀態：列出版本、通知、權限、行程名稱或錯誤內容。
- 網路邊界：說明哪些請求被關閉、攔截或不會發生。

## 設備環境

- 語言：`zh-Hant-HK`
- 主題：`light`
- Font scale：`1.0`
- 方向：`portrait`
- 設備畫像：列出 API、解析度／寬度及 Google APIs／Play 等硬條件。
- 截圖模式：`app-area`
- 系統狀態：列出時間、權限、鍵盤、通知、鎖屏等要求。

## 資料注入

- 選擇層級：填寫既有 store、existing seam、fake server、temp seam 或 reflection。
- production UI：列出實際 renderer 與 navigation path。
- 實作位置：只列預計在隔離副本使用或新增的檔案。
- 穩定條件：列出斷言、idling 或狀態輪詢方式。

## 驗收條件

- 內容：列出功能狀態、焦點和必須可見的文案／數值。
- 視覺：列出不截斷、不重疊、不遮擋及主題要求。
- 安全：列出合成資料、地名與 PII 檢查。
- 技術：列出 PNG 名稱、數量、尺寸及裁切方式。

## 清理

- 原倉庫清理：`pending`
- 模擬器清理：`pending`
- 任務工作區：完成後刪除 `workspace`，保留 `output` 與 `manifest.md`。
- App／設備資料：列出通知、權限、App data、service、locale、theme、font scale 及 temp AVD 的清理方式。

## 限制與失敗

- 已知限制：列出本次不覆蓋的尺寸、語言、網路或互動驗證；沒有就寫「沒有已知限制」。
- 失敗策略：任一步失敗都先清理，再把狀態與證據寫入 manifest，不輸出近似替代畫面。
```

## 狀態轉換

- 使用者確認前：模板只存在會話，禁止任何寫入或設備操作。
- 獲批執行時：`任務狀態=planned`、兩項清理為 `pending`，用 `--phase contract` 校驗。
- 成功收尾：`任務狀態=passed`；兩項清理都有證據後改為 `passed`。
- 執行失敗但已完全清理：`任務狀態=failed`；兩項清理仍應為 `passed`，並記錄失敗。
- 任何清理失敗：不要把該項改成 `passed`，也不要把任務稱為 complete。

檔名只用小寫英數、點、連字號或底線，並以 `.png` 結尾；場景 slug 只用小寫英數及單一連字號分隔。
