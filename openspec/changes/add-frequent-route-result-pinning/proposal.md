## Why

常用頁一次查詢可能返回大量巴士路線，而既有排序只能反映單一欄位，無法讓用戶持續關注不符合目前排序優先級的特定路線。需要提供不佔用卡片常駐操作空間的置頂能力，讓用戶能以橫滑手勢建立本次或長期偏好，同時保持排序、刷新、ETA 更新與長列表瀏覽的穩定性。

## What Changes

- 僅在「常用」頁的已保存行程查詢結果中新增路線卡片橫滑置頂；搜尋頁與臨時查詢結果不提供此能力。
- 普通路線向右滑動後成為本次置頂；本次置頂再次向右滑動或點擊 Snackbar 操作後升級為該行程的長期置頂；任何已置頂路線向左滑動後直接取消全部置頂狀態，並可透過 Snackbar 撤銷。
- 所有置頂路線共用一個後置頂在上、先置頂在下的區域；普通排序只作用於未置頂路線。置頂區域與普通區域以包含目前排序說明的橫向分隔列區分，不新增常駐分組標題。
- 本次置頂在目前 Android task 及同一行程上下文內保留，於切換行程、修改起終點、刪除行程、明確取消或全新啟動時清除；長期置頂按已保存行程持久保存，重新啟動後依原順序恢復。
- 使用不受語言、票價、耗時、步行距離、ETA 或展示文字影響的版本化嚴格路線指紋辨識同一乘車方案；無法建立唯一身份時拒絕置頂，不進行模糊匹配。
- 新增長期置頂的 SQLite 儲存與非破壞性資料庫升級；行程重命名保留置頂，修改起終點前提示並清除長期置頂，刪除行程時級聯刪除。
- `.bicroutes` 版本 1 仍只交換行程定義，不匯出或匯入本次／長期置頂偏好；複製或匯入所得的新行程不繼承置頂。
- 以 DiffUtil 穩定身份與卡片移動／回彈動畫支援長列表互動；保留目前視口，不因置頂或取消置頂自動捲動。補充 TalkBack 自訂操作、置頂狀態描述及繁體中文、簡體中文、英文資源。
- 不限制每個行程的置頂數量；不新增卡片常駐按鈕、長按入口、首次使用教學或搜尋頁置頂。

## Capabilities

### New Capabilities

- `frequent-route-result-pinning`: 定義常用行程查詢結果的本次／長期置頂狀態機、順序、手勢、視覺、生命週期、嚴格身份、持久化、錯誤恢復與無障礙契約。

### Modified Capabilities

- `bus-route-results-sorting`: 將使用者選擇的排序限定於未置頂結果，並保證置頂區域不受排序字段、方向或漸進資料更新重排。
- `route-query-results-layout`: 在常用頁結果清單加入可選分隔列、置頂卡片狀態與穩定列表移動，同時保持總數摘要、觸控區、視口和卡片版面。
- `route-config-management`: 明確行程重命名、起終點修改及刪除對長期／本次置頂的保留、確認、清除及原子性行為。
- `saved-route-transfer`: 明確 `.bicroutes` 版本 1 排除置頂偏好，匯入、複製及取代流程不繼承置頂並正確清理被刪除行程的關聯資料。

## Impact

- 主要影響 `ui/main` 的結果投影、RecyclerView adapter、ItemTouchHelper 手勢、Snackbar、卡片 drawable／layout 與 Activity 狀態恢復。
- `data/model` 與 `data/repository` 將新增版本化路線指紋、置頂狀態及純排序投影；`data/local` 將把 SQLite schema 由 v3 非破壞性升級至 v4，新增按行程關聯的置頂資料表、唯一鍵、排序索引及外鍵級聯。
- 行程編輯、刪除、複製與匯入／取代 transaction 需要協調關聯置頂資料；現有 `.bicroutes` 格式與版本保持不變，既有行程、使用統計及外部 Citybus／DATA.GOV.HK 接口不變。
- 新增的 App 自有文案、Snackbar、錯誤、content description 與 TalkBack action 必須同步提供香港繁體、獨立審校的簡體及自然英文資源。
- 驗證涵蓋狀態機、LIFO 順序、排序投影、指紋穩定性、SQLite v3→v4 遷移與回滾、並發寫入、DiffUtil／滑動門檻、三語×明暗色、360dp、font scale 1.0／1.3／2.0、TalkBack，以及最終 `./gradlew build`。
